CHAPTER 01

Small machine. Serious music.

TrackWerk 1.3.0 is a free, open-source eight-track music studio for handhelds. Build a beat from samples, shape a synth patch, perform an effect, and turn the result into tomorrow's starting point.

Try this

  1. Start with a demo project and press START. Watch which track does what before changing anything.
  2. Open a copy of the project, change one phrase, and save it under a new name.
  3. Explore Studio when you want a new sound, rhythm or recording. Return to the tracker to arrange it.

What is new in 1.1

Forty complete Scenes combine layout, colour, material and lettering. Daylight and Hardware join the terminal, BBS, DOS, raster and vector looks. Cursor movement, tabs, scrolling lists and controls can animate; Motion can also be switched off.

A complete working loop

The tracker, Sample Editor, Studio, Drumlab, Harmony, Source Sampler, Punch and internal resampling are connected parts of one workflow. You can move from a recording to slices, from slices to a phrase, and from a performance back to a sample.

How to use this book

Work through the illustrated chapters first. The later core reference explains individual tracker pages, commands and file operations in more detail. Screenshots are generated by the actual 1.1 renderer at its native 640 x 480 canvas; scripted navigation is used for clarity.

Begin with a musical idea, not a tour of every menu. The menus will still be there after the bass drops.

CHAPTER 02

Choose the right package

The music workflow is shared. Installation and connectivity follow the device. Match the download to the operating system already on your handheld.

Try this

  1. Back up your TrackWerk data folder and SD card before updating. Keep projects, samples and the previous program together.
  2. Choose First Install for a card without TrackWerk. Choose Program Update for an existing installation, then follow that ZIP's START-HERE instructions.
  3. For Android, install the signed APK over the existing TrackWerk app. Keep the app installed and keep its granted working folder.

Brick and RGB20S

The Brick package targets KNULLI. The RGB20S package targets AmberELEC and belongs on the games card when using a two-card setup. A package for another firmware is not interchangeable just because its processor is ARM.

PortMaster (alternative)

On a handheld that already runs PortMaster — KNULLI, AmberELEC, ArkOS, ROCKNIX or muOS — install TrackWerk in one step. Drop the PortMaster ZIP into roms/ports/PortMaster/autoinstall, run PortMaster once, and TrackWerk is added to your Ports list with cover art. The ZIP includes the aarch64 program and five internal-synth demo projects.

Miyoo Mini and Mini Plus

Use the Onion package for the exact model. Both menus display TrackWerk 1.3.0. The Mini package is local/offline; the Plus Archive profile adds supported online source access. An additional offline installation is labelled TrackWerk 1.3.0 Offline.

Android updates

Version 1.3.0 uses package com.kidbunka.trackwerk and the existing release signer. Its versionCode is 103000, higher than the 1.0 release and the 1.1 development APK. Uninstalling is unnecessary for an ordinary update and can remove app-private data.

Factory content

The factory library contains 2,432 presets. Install its folder structure as supplied. The public demo project collection uses internal synth engines; soundtrack compositions with commercial sample-library material are supplied as mixed audio, not as raw sample packs.

Never copy a whole factory card image over your music card just to update one program.

CHAPTER 03

Eight buttons and a few good habits

The D-pad moves. A confirms or inserts. B cancels or clears. R navigates between screens. The combination shown in the footer is your local map.

Try this

  1. Move to a cell and tap SELECT for contextual help. Read the help for that exact cell or Studio page.
  2. Hold A with Left or Right for a small value change. Up or Down normally makes a larger change; list choices step through their entries.
  3. Hold R and use the D-pad to move around the screen map. START plays or stops in the context of the active page.

Modifiers are deliberate

A quick A on a link opens it, while A with a direction edits the value. Some links open on release so that editing does not accidentally enter another screen. B with Left/Right changes the current item or walks the song arrangement, depending on the NAV setting.

Help and escape routes

SELECT is context sensitive. In Studio it explains the selected workspace and its controls. B closes a dialog or returns from an editor. In a confirmation, read what the next A press will commit before pressing it.

Copy without surprises

On SONG, CHAIN, PHRASE and TABLE, L+B enters selection and cycles its extent. B copies the selection. L+A pastes outside a selection or cuts inside one. L+R exits selection; outside selection it can clear a retained clipboard or restore muted tracks, most recent action first.

If the screen suddenly feels like a different instrument, check the held modifier before blaming the jazz.

CHAPTER 04

Make your first sixteen steps

A phrase is sixteen steps. Time runs down the screen. Start with one sound and a clear pulse; variation is much easier once there is something worth varying.

Try this

  1. Load a demo or a sample into an instrument slot. On PHRASE, choose the instrument number in the INST column.
  2. Place kick notes at steps 0 and 8. Put a snare on steps 4 and C, then add quieter hats between them.
  3. Press START to audition. Change velocity before adding more notes. Save a copy once the groove feels useful.

Reading the columns

NOTE gives pitch or a stop event. INST chooses the sound. VOL sets the event's level. FX1, FX2 and FX3 apply tracker commands. The values and identifiers are hexadecimal: after 9 come A through F.

Feel before density

A repeating velocity on every hat often sounds more rigid than the timing grid itself. Alternate strong and quiet hits, leave a gap before a snare, and let the kick establish the downbeat. Swing can move the offbeats, but it cannot decide which notes matter.

Make a second phrase

Copy the first phrase to an empty slot, alter a fill or bass ending, and keep the original intact. The song can then alternate the two phrases without changing every use of the first one.

Four well-placed hits are a beat. Forty badly placed hits are an incident report.

CHAPTER 05

Phrase to Chain to Song

Phrases hold notes. Chains hold phrase references and transposes. SONG places chains on eight tracks. Reuse makes the arrangement compact; deliberate cloning makes variations independent.

Try this

  1. Open CHAIN and enter the phrase references in the order you want them to play. Give the last phrase a small variation.
  2. Open SONG and put a chain on each active track. Arrange an introduction, full section, break and return.
  3. Play from SONG and listen across the section boundaries. Use a chain of empty phrases for a timed rest where alignment matters.

References are shared

Editing a phrase changes every place that references it. If only one occurrence should change, clone it into a free slot first. The same principle applies to a chain reused at several song positions.

Tracks have their own lengths

Tracks advance through their chains independently. Unequal chain lengths can produce evolving patterns, but can also make a four-bar part lose alignment. An empty song cell is not the same thing as a measured four-bar rest.

NAV setting

With NAV set to SONG, B+D-pad walks the arrangement and skips empty cells. With NAV set to POOL, the same navigation can inspect unused chain and phrase slots. Switch to POOL when looking for material that is not placed in the song.

A copied reference is a shared idea. A deep clone is the point where the idea gets its own apartment.

CHAPTER 06

Build a useful sound library

Use presets to start quickly, then keep a small personal collection of sounds that suit your music. A tidy browser is a performance tool.

Try this

  1. Open the instrument or preset browser from the relevant LOAD cell. Use A to enter a folder and B to return.
  2. Preview an appropriate preset or sound before committing it to a slot. Choose a free slot when protecting an existing part.
  3. Save your own named instrument, scale, groove or effect preset after making a useful change.

Factory organisation

The supplied library groups instruments and musical settings by type. Keep its Presets hierarchy intact rather than flattening everything into one huge folder. This also makes later factory updates easier to recognise.

SoundFonts

SF2 and SF3 instruments are selected from a bank through the instrument interface. The chosen patch is loaded rather than treating the entire bank as one giant sample. A different patch can change memory use and loading time.

Portable projects

A project file describes the arrangement and sound settings; external media still needs to be reachable. Use COLLECT before moving a project between computers, phones and cards, then test the collected copy.

Name the sample before it becomes final_final_reallyfinal_07.wav.

CHAPTER 07

Meet Studio

Studio brings sound design, rhythm, recording and performance workspaces together. Its controls are designed for the same D-pad and modifier vocabulary as the tracker.

Try this

  1. Open Studio with R+SELECT. Use B+Left/Right to move between music workspaces.
  2. Use B+SELECT to open the workspace selector when you want to jump directly to another section.
  3. Move to a parameter, edit with A+D-pad, and use SELECT for that page's exact audition and apply controls.

Workspaces

Synth, FX, Master, Punch, Record, Drumlab, Sources and Harmony each concentrate on a different musical task. Appearance lives with the visual settings. Tabs and headings show where input will go.

Preview and apply

A sound preview is a way to judge a choice before replacing project material. The Apply action is explicit. Watch the target instrument and any confirmation message when sending a generated sound or pattern into the song.

Return to the arrangement

Leave Studio and play the project in context. A patch that sounds huge on its own can hide a snare or bass line in a full mix. Use the tracker and mixer to decide whether it actually belongs.

Browse boldly. Apply deliberately. That is the whole lab safety briefing.

CHAPTER 08

A synth laboratory in the cartridge slot

TrackWerk offers 123 synth models and sixteen variation positions per model. Family browsing makes this large collection manageable without requiring you to learn every engine first.

Try this

  1. Choose a family and model. Start with a variation close to the role you need: bass, chord, percussion, texture or lead.
  2. Hold L to audition the current synth, then change one parameter at a time. Move between the model's pages when needed.
  3. Apply to the intended instrument slot, return to PHRASE, and test the patch at the actual note range and velocity.

Different models, different jobs

SID CHIP adds a chip-voice family; DCO POLY covers polyphonic DCO-style colour. Spectral models explore additive, morphing and freeze-like textures. Model names describe their role, but the best choice still depends on the arrangement.

Preset variations

Variation positions provide starting points rather than sixteen promises of a completely different synthesizer. Once you edit a patch, treat it as your own sound and save it with a useful name.

Performance and voices

The amount of sound a handheld can sustain depends on the active models, polyphony, effects and device. Build the part on the device profile you intend to use. No single voice-count benchmark describes every patch and mix.

A new oscillator is exciting. A bass note that leaves room for the kick is useful.

CHAPTER 09

FM SysEx: give a bank a second life

FM SYSEX loads DX7-format voice banks and stores the selected voice with the song. The sound you chose should travel with the musical idea.

Try this

  1. Use the FM SysEx model and the bank browser shown by the model's controls. Keep your compatible banks in the SysEx folder used by the app.
  2. Load a supported bank, select a voice, and audition it at a sensible level. Different FM patches can have very different envelopes and brightness.
  3. Apply the voice to an instrument, save the project, then reopen it and check that the same voice returns.

Compatibility scope

This is DX7 voice-bank import for the FM model. It does not mean every manufacturer's SysEx dump, performance setup or MIDI librarian format is accepted. An invalid or unrelated file is not a new synthesis model.

Song storage

The optional fmVoice project field lets the selected voice be saved with the song. Older projects without this field remain valid and use their existing sound data.

Musical use

FM can provide an electric piano, struck metal, a rounded bass or a shifting texture. Start with velocity and envelope behaviour before adding brightness; harsh upper partials become much more obvious when several tracks compete.

The bank may be vintage. The chord progression is allowed to be new.

CHAPTER 10

Harmony: keep the good chord

Forty-eight progression templates provide starting points, not an automatic songwriting verdict. Lock what works, regenerate what does not, and write an editable result into the tracker.

Try this

  1. Choose a style, key and progression length, then select the sample, SoundFont or external MIDI instrument used for preview.
  2. Audition the chord slots. Lock a useful slot and generate again to change the unlocked material.
  3. Use Write Phrase on an empty destination and confirm it. Inspect the resulting notes and adjust the voicing in PHRASE.

Preview source

Harmony preview uses a loaded sample, SoundFont or external MIDI instrument. Direct Studio synth preview is a different path. Choose an instrument that can sustain a chord long enough to judge the movement.

Voicing matters

The same chord symbols can sound gentle or crowded depending on register and spacing. Try a compact voicing, then move a voice by an octave. Keep the bass range clear before deciding a progression is too busy.

An editable result

Writing the phrase is a starting point for sequencing. Move a note, add a pickup, omit a chord, or let a held tone cross a bar. A generated progression becomes a composition when you make choices about it.

Lock the good bit. This works for chords and, occasionally, band rehearsals.

CHAPTER 11

Drumlab: generate, listen, edit

Drumlab can suggest rhythms using your loaded sounds. It also gives you lane locks, Euclidean settings, map-based patterns and a step grid for making the result intentional.

Try this

  1. Assign the drum sounds you actually want to hear to the lanes. Choose a style and pattern length.
  2. Generate, preview, and lock the lanes that work. Change density, rotation, swing or a lane's hits instead of regenerating everything.
  3. Edit a few velocities or steps in the grid, then Apply to Song and inspect the new phrase material.

Euclidean and map patterns

Euclidean settings distribute a chosen number of hits over a period and rotate the result. Map mode blends rhythm nodes with X/Y and uses density and Chaos to vary the outcome. Neither mode knows which fill your chorus needs.

Human detail

Alternate hat levels and articulations, add a quieter snare pickup, and remove the hit that competes with the bass. Good sample choice and phrasing often matter more than a global humanize number.

Applying safely

Drumlab uses free, unreferenced resources and appends new material rather than casually overwriting a working phrase. If the project has no suitable free space or an assignment is invalid, read the status and free or correct the target deliberately.

The generator is a drummer with suggestions. You are still producing the record.

CHAPTER 12

Digging in the Source Sampler

The Source Sampler combines finding a recording, listening, marking a range and importing it. It keeps source information visible so that discovery does not turn into a folder of anonymous files.

Try this

  1. Open Sources in Studio, select Internet Archive, and enter a specific search. Collections help narrow a large catalogue.
  2. Open a result, inspect its recording list and source information, then start a preview.
  3. Choose the recording you want to sample. Check the item's rights information before using it in music you will distribute.

Providers and devices

The available online providers depend on the platform and installed helper support. The Mini offline profile uses local media. YouTube is off by default and is only enabled through an explicit user choice, saved as sourceYoutube.

Rights travel with the decision

A public recording can still have conditions. A search filter is useful, but is not a grant of rights. Keep the source URL, creator, track title, licence and any required credit with your project notes.

Search like a producer

Look for a musical role rather than only a genre: a piano turnaround, a held horn, a room sound, a clean break. Preview the beginning and end of a candidate phrase before deciding where the loop should breathe.

An archive is a record shop with a very long aisle. Bring curiosity and a bookmark.

CHAPTER 13

From archive recording to useful range

The walkthrough uses Jimmy Blythe's Armour Avenue Struggle, a 1924 piano recording. The displayed source states come from a recorded native provider session replayed through the current interface.

Try this

  1. Preview the recording and stop near the start of the phrase you want. Set the IN marker, then find and set OUT.
  2. Listen to the whole selected range, including its tail. Check that a pickup note is not cut off and that the end leaves enough room to edit.
  3. Export the range, choose a free target instrument and open it in the Sample Editor. Keep the source and licence note with the project.

What is shown

The captured example uses the 14-second region from 00:01.100 to 00:15.100. It is an instructional source selection, not a claim that every soundtrack demo was made from this one recording.

Take a little extra

A musically clean edit often needs audio just before the first transient and after the final release. Select a useful phrase with some margin, then make the precise cut in the editor.

A range is not a song

Once imported, the recording is raw material. You can leave a phrase intact, split it, reorder it, or process it. Keep an untouched source copy so that an enthusiastic edit does not become an archaeology assignment.

Find the phrase first. Count the bars second. Blame the drummer only after checking the original tempo.

CHAPTER 14

The Sample Editor: listen at the boundary

Zoom, selection, slice markers and audition make a sample into a playable instrument. Work from the whole recording down to the transient, then return to musical time.

Try this

  1. Open EDIT from the instrument or import a recording into a free slot. Audition the whole sample before changing it.
  2. Use the waveform view and zoom controls to locate the attack. Place a selection that includes the sound you mean to keep.
  3. Audition the selection at its intended pitch. Make one edit, compare it, and use Undo when the result does not help.

Selection and view

Zoom changes how much audio is visible; selection chooses the audio an operation targets. A narrow view does not automatically mean a short sample. Return to an overview before a large cut or export.

RATE and pitch

Changing the editor's RATE mode affects its working rate. Pitch-related playback and exported sample rate are related but distinct decisions. Check the saved result at its intended pitch rather than judging only the waveform width.

Protect the performance

Keep a source copy and save a new sample when making a major transformation. If saving fails, read the message and retain the edited material until a successful save or a deliberate discard. Do not equate closing the editor with having saved a new file.

The perfect-looking transient can still sound wrong. The waveform is evidence; your ears make the decision.

CHAPTER 15

Slices that groove instead of stutter

Equal slices are a useful starting ruler. Musical slices follow attacks, pickups and tails. Use the grid to get organised, then edit what you hear.

Try this

  1. Choose a divide method and a sensible count, such as sixteen slices for a four-bar source. Audition several slices, not only the first one.
  2. Move boundaries where the original performance pulls ahead or hangs back. Keep small tails when they make the next hit feel natural.
  3. Use CUT-style slicing to trigger the pieces from notes. Start with the original order, then change a small number of events.

Pitch and slice number

In the supplied rhythm templates, C-4 triggers the first slice and successive semitones step through the slices. A sixteen-slice source runs through D#5. Confirm the instrument's slicing mode before treating note values as slice choices.

Loop versus chops

A whole loop depends on its original length and playback speed. Separate chops let you arrange events independently, but can expose gaps and cut tails. Use both approaches when building an introduction, a break and a rearranged return.

Audition at tempo

A boundary that sounds smooth in isolation can click or feel late once the kick enters. Test the phrase in the song, lower the chop level if it masks the snare, and keep the most recognisable motif long enough to feel like music.

A sixteen-slice grid is a ruler, not a court order.

CHAPTER 16

Gain, CHOP and a clean exit

Gain is a level decision. CHOP is a review-and-export workflow. Neither replaces checking the result in the arrangement.

Try this

  1. Open Gain from its editor action. Start with a modest change and audition before accepting it.
  2. Open CHOP, inspect the detected or divided pieces, and use the preview control to check the beginning and release of each important slice.
  3. Export only after the review. Save the project and test that the exported sample files load from the intended folder.

Leave headroom

A louder isolated sample is easy to prefer. Compare at similar listening level and consider how several loud samples add up. A little room above the sample is useful when applying effects later.

Undo and working copies

Undo is a way back through supported editing operations, not a backup plan for a card or a whole production session. Keep the original recording and a saved project copy before an extended editing pass.

Name the musical role

Name a chop for the source or role rather than only its ordinal number. A readable project six weeks later is worth more than saving three seconds during the export.

Normalise the sample if it helps. Your artistic self-confidence can remain unnormalised.

CHAPTER 17

A recording becomes an instrument

Sample Granular takes a loaded recording into a different sound-design workflow. Instead of only replaying the original phrase, explore small regions, position and texture.

Try this

  1. Load a source into Sample Granular from the Synth workspace. Choose a short region with an interesting tone or attack.
  2. Audition while changing one parameter at a time. Notice the difference between changing where you listen and changing how the grains behave.
  3. Apply a useful sound to a slot and test it in a phrase. Save the preset and keep the required source media with the project.

Choose source material

Sustained piano tails, breaths, cymbal decay and a tiny chord can make very different textures. A dense stereo loop is not automatically more useful than one clear sound.

Keep a tonal role

If the result is a pad, leave space for the lead. If it is percussion, shorten or gate the busy tail. A texture becomes easier to arrange once you decide whether it supports rhythm, harmony or atmosphere.

Portability

A granular preset that depends on an external recording still needs that recording. Collect the project before moving it to another device, and reopen the collected copy rather than assuming a path will resolve.

There is a point where a piano becomes weather. Give it a name before that happens.

CHAPTER 18

Punch: hold the move, release the mix

Punch is a momentary performance layer: eight banks of eight pads. Choose an effect, hold A, and release to return. Use it to emphasise a phrase, not to obscure every downbeat.

Try this

  1. Open Punch, select a bank with the shoulder controls, and move to the desired pad. Start with a moderate listening level.
  2. Play the song dry for a few bars. Hold A for a deliberate interval, then let go and listen to the return.
  3. Try Low Pass, Dub Echo and Echo Freeze on the same passage. Record a performance only once the moves support the arrangement.

Hear the before and after

A convincing demonstration gives the dry groove time to establish itself. Then let the effect act long enough to hear its envelope and tail. The film leaves longer dry/wet passages without narration for this reason.

Momentary does not mean random

Bring a filter in before a section change, catch the last chord with a freeze, or use an echo as a response to a fill. Release on a musical boundary so the original groove returns with purpose.

Record the performance

Internal resampling can capture the audible post-effect result. Once it is saved, the take can become a new sample, an arrangement layer or a source for another round of sound design.

An effect is punctuation. A track written entirely in exclamation marks is tiring.

CHAPTER 19

Record the good accident

Internal resampling captures the mix, including the effects you perform. The recorded take is saved before it is loaded into a free instrument.

Try this

  1. Set the take length with B+Down in a supported Studio or recorder context. Choose Free or a bar length suitable for the phrase.
  2. Use L+R+START to start or stop internal resampling. Perform the desired move, then wait for the take to finish saving.
  3. Stop song playback and use B+Up to load the saved take into an empty target. Open it in the Sample Editor and save the project.

Take length

The available choices include Free and 1, 2, 4 or 8 bars; recording is capped at sixty seconds. The requested bar count depends on tempo. A fixed musical length makes it easier to align the take in a new phrase.

Use a free target

The use-take action protects occupied instruments. If the target is not empty, choose a free slot; the saved take remains available. Unsaved edits in the current sample editor must be resolved before replacing its working material.

External input

External recording depends on the platform and connected audio hardware. Internal resampling does not prove that a particular handheld has a microphone or USB input driver. Check the actual input selection on the device.

A happy accident is better after it has a filename.

CHAPTER 20

Mix for the song

Track balance comes before mastering. Let the kick and bass agree about the low end, keep the lead audible, and use the send returns as part of the arrangement.

Try this

  1. Balance the tracks at a comfortable listening level. Lower competing parts before raising the master.
  2. Mute or solo a track with R+B or R+A on SONG or MIXER. Use L+R to restore full playback when needed.
  3. Add reverb and delay deliberately, then compare the mix with and without them. Save a useful effect or master setting as a preset.

Returns are musical

Reverb can place a sound behind the beat; delay can answer it. Too much of either can hide the transient detail you worked to preserve in the editor. Use the return controls to judge the effect itself.

Hold or latch

For mute and solo chords, release order determines momentary or latched behaviour: releasing R first keeps the change; releasing A or B first restores the previous state for that chord. Test this on a demo before using it in a performance.

Master tools

Dynamics, saturation, stereo width and output controls are useful after the balances make sense. A limiter is not a prize for reaching the top of the meter. Compare at equal loudness and leave headroom.

The red lights are not a high score.

CHAPTER 21

Export something you can come back to

Render a mix for listening, stems for further production, and a collected project for moving the session. These are three different deliverables.

Try this

  1. Save the project under a clear name. Use COLLECT if the session depends on external samples or other media.
  2. Choose the export type and range on PROJECT. Render a mix for a listener, or stems when continuing in another audio tool.
  3. Open the exported WAV and the collected project from their destination. Check the first note, final tail and any section boundary you edited.

A WAV is not a project backup

The mix contains the sound but not editable phrases, instrument definitions and source links. Keep the .ptp project and its required media when archiving a session.

Filesystems differ

Android document providers and handheld SD cards have different capabilities. Let a save operation finish and read its result. If a file cannot be published, keep the working material and choose a writable destination.

A practical archive

Store the project, collected media, final mix, source credits and a short note about tempo and version together. A second copy on another drive is more useful than three differently named files on the same card.

Backups are the least exciting part of a song, right up to the moment they are the best part.

CHAPTER 22

Forty Scenes. Your kind of noise.

A Scene is a complete visual starting point. A palette changes colours. A typeface changes lettering. Keep these decisions separate when tuning readability.

Try this

  1. Open Settings, Appearance, then Design Collection. Press A to browse Scenes.
  2. Move Left/Right between families and Up/Down through the looks. Apply with A or leave with B.
  3. Adjust palette or typeface independently. Turn Motion off for a still interface and compare the result while a dense page is open.

Ten design families

UNSCII, ASCII, DOS, Terminal, ANSI BBS, Raster, Crack Intro, Vector, Daylight and Hardware each have four presets. The forty choices change more than a background colour; they provide a coherent visual personality.

Readable in different conditions

Daylight offers light backgrounds including Newsprint, Sunny LCD, White Print and High Contrast. Hardware includes Alu OLED, Orange Keys, Cream Case and Bunka Signal. Choose with the actual device brightness and lighting in mind.

Motion with a stop button

Cursor glide, list movement, page changes, tab selection and animated controls settle onto the final interface. Motion is optional. The editor content is not meant to wander merely because the clock advances.

Independent customisation

There are 54 built-in palettes and sixteen optional typefaces. A font with lots of character may be lovely on a title and less helpful in a dense parameter list. Try a whole phrase, mixer and sample editor before choosing.

The wardrobe is unreasonable. The controls remain familiar.

CHAPTER 23

Play a track, not the menu

Preparation makes a small handheld feel like an instrument. Keep one reliable project, a manageable set of moves and a way back to the dry mix.

Try this

  1. Decide which tracks you will mute, which Punch moves you will use, and whether you will record the performance.
  2. Practice the transitions at the actual song tempo. Give delays and reverbs time to decay when that is part of the move.
  3. Save the finished project, test the device's audio connection, and keep the previous working version available.

Reduce surprises

Use familiar sounds for a performance rather than loading a completely different bank just before playing. If a project is close to the device's limit, simplify the sound or visual workload and test the actual arrangement.

MIDI

The MIDI page exposes the ports and routing supported on the platform. Choose the output and input you intend to use, then test notes and clock with the real connected instrument. A screenshot showing NO PORTS is a valid disconnected state.

Troubleshooting audio

Check track mute and solo state, master level, instrument assignment, note range and output connection before rebuilding the song. For a sample, check that its media loaded and that the selected region contains audible material.

Confidence is knowing the exit chord. Also knowing which button unmutes the bass.

CHAPTER 24

When the groove goes missing

Most problems become simpler when you reduce them to one track, one note and one expected result.

Try this

  1. Save a copy before diagnosing. Stop playback, clear an unintended mute or solo state, and test one known working sound.
  2. Check the page's contextual help and the project's media paths. Reopen a collected copy when testing portability.
  3. For a report, include the device profile, version, exact steps and a small project that reproduces the problem.

Missing samples

A project can point at media that exists on another card or folder. Restore the files or relink them, then collect the session. Renaming only the .ptp file does not copy its sample dependencies.

An update refuses a program

The Miyoo updater recognises verified predecessor binaries so it can avoid replacing an unknown program. Read the plan and use the matching package. Do not force an unrecognised file into the accepted list merely to get past a check.

No online sources

Check the profile first: Mini offline is deliberately local. On a capable profile, check network access, the provider and helper status. YouTube remains disabled unless you explicitly choose to enable it.

A design is too busy

Try a simpler Scene, a clear typeface, Motion off and a lower-work visualizer such as FLAT. Visual preference and audio workload are both reasons to keep these options available.
